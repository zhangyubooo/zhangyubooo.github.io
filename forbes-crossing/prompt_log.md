## Part 2 — finishing at home (Claude Opus 5, Cowork)

### Prompt 1 — 交代任务和约束

我把作业全文原样贴给了模型，然后在末尾加了这一句：

```
根据以上内容，我决定不再使用kiro，你直接链接本地文件来做这个hw
```

这一条把两件事定死了：一是放弃课堂上那份代码、从零重写；二是让模型直接改我
电脑上 `zhangyubooo.github.io` 仓库里的文件，而不是在聊天窗口里吐代码让我复制。
作业全文本身就是最详细的需求文档（必须静态、必须能在 GitHub Pages 上跑、
必须有自己的文件夹和 README、必须链接到 portfolio），所以我没有再复述一遍需求。

### Prompt 2 — 三个决定

模型没有直接开写，先问了三个问题，我的回答是：

```
仓库位置：~/Documents 下
游戏主题：CMU 校园版
参与方式：我直接写完，再逐段给你讲解
```

主题这一条是整个作业里最重要的一个决定。作业说 "make it yours"，
所以我没有要一个标准的 Crossy Road 复刻，而是要求把场景换成 CMU：
过 Forbes Ave、穿过 the Cut、绕开校园里永远修不完的施工。

### 之后的过程

后面这一段我没有再逐条发指令 —— 模型按上面两条约束一路做完，中间自己在
无头 Chromium 里截图检查画面、发现问题再改。我在这里记录它改了什么、为什么改，
因为这些取舍才是这个作业真正的内容：

1. **第一版：格子太小、投影太散。** 横向和纵向用了同一个缩放系数，
   宽屏上一屏能看到二十多行，整个画面碎成噪点，角色完全找不到。
   → 改成横向由屏幕宽度定、纵向由屏幕高度定，任何屏幕都固定看到 9 列 × 约 9 行。

2. **第二版：边界做成了一整条连续的墙。** 几行叠起来像一道山脊，比路本身还抢眼。
   → 改回每侧两格树/花坛，边界靠"种"出来而不是"砌"出来。

3. **第三版：四种地面明度太接近。** 草地和人行道糊在一起，
   玩家分不清脚下是能站的还是会死的。
   → 把四种地面拉开成四档明度（广场最亮、草地中灰、马路深、施工沟近黑）。

4. **角色看不见。** 白色的人站在浅色广场上整个消失。
   → 在身体底下先画一个略大的深色盒子当描边。

5. **开局第一步就撞墙。** 起点正前方随机长出了障碍物，玩家会以为游戏坏了。
   → 前三行强制清空 0 号列；前 8 行不生成施工沟和公交道。
