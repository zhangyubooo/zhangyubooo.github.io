Ask Yubo

AI Chat · Backend + Frontend · 2026

A chat with an AI version of me, available from the round button in the bottom-right corner of every page on this site. Ask it about my projects, what I study, or how I like to work — it answers in my voice, using only what is already published here.

How it works

This site is static: plain HTML, CSS and JavaScript on GitHub Pages, where anything in the code can be read by anyone who opens the browser's developer tools. A chatbot needs a secret API key, so it can't live here on its own.

Instead, the chat window sends each question to a small Python (Flask) backend I deployed on Render. The backend checks the message, adds a description of who I am, asks an AI model with the key it keeps in an environment variable, and sends the reply back as JSON.

Browser (GitHub Pages) → Flask backend (Render) → AI model (gpt-oss-20b via Groq) → back to the browser

Decisions

  • The key never reaches the browser It exists only in Render's settings and in a local file that Git ignores.
  • The server remembers nothing The browser keeps the conversation and sends it with every question — no database, and the chat follows you from page to page.
  • A public endpoint needs guarding Anyone can call the backend directly, so every message is checked and each visitor is rate-limited before the AI is asked anything.
  • Failing politely The free server sleeps when idle. The page wakes it early, says so when a reply is slow, and keeps undelivered messages so they can be re-sent.
  • It shouldn't make things up An early test said my degree was five years long. It's four. The persona now states it, forbids embellishing, and the model runs cooler.
